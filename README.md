# COSC 442 Project 1 - Monopoly

This repository contains the Monopoly project used for COSC 442 Project 1.

## Testing

The project includes JUnit tests for the Monopoly application. The complete test suite should pass after the refactoring changes.

## Documentation

Generated Javadocs are stored in the `javadoc` directory. Open `javadoc/index.html` to view the documentation.

## Refactoring

The project includes refactoring work involving field renaming, method extraction, local-variable extraction, and code-quality improvements identified with SonarQube and Cyclomatic Lens.
